# Задача «Комплексные числа»

## Описание

Необходимо реализовать модуль для работы с комплексными числами. Комплексное число представляется в виде $a + bi$, где $a$ — действительная часть, $b$ — мнимая часть, $i$ — мнимая единица ($i^2 = -1$).

## Требования

### Структура модуля

Создать два файла:

* `complex.h` — объявления типов и прототипы функций.
* `complex.c` — реализация всех функций модуля.
* `test_complex.c` — тесты для всех операций.

### Структура `Complex`

Комплексное число задаётся структурой:

```c
typedef struct ComplexNum {
    double re;
    double im;
} Complex;
```

### Функции
Реализовать следующие операции: 
1. **Арифметические операции**:
    * сложение двух комплексных чисел: $(a_1 + b_1i) + (a_2 + b_2i) = (a_1 + a_2) + (b_1 + b_2)i$.
    * вычитание двух комплексных чисел: $(a_1 + b_1i) - (a_2 + b_2i) = (a_1 - a_2) + (b_1 - b_2)i$.
    * умножение двух комплексных чисел: $(a_1 + b_1i) \cdot (a_2 + b_2i) = (a_1a_2 - b_1b_2) + (a_1b_2 + a_2b_1)i$.
    * деление двух комплексных чисел (убедиться, что делитель не равен нулю): $\frac{a_1 + b_1i}{a_2 + b_2i} = \frac{(a_1a_2 + b_1b_2) + (a_2b_1 - a_1b_2)i}{a_2^2 + b_2^2}$.

2. **Возведение в степень**:
    * возведение комплексного числа в целую степень (может быть отрицательной).

3. **Конструирование**:
    * создание комплексного числа из действительной и мнимой частей.

4. **Сравнение**:
    * сравнение двух комплексных чисел на равенство (комплексные числа равны, если равны их действительные и мнимые части):
        * возвращает $-1$, если числа не равны;
        * возвращает $0$, если $a = b$ (действительные и мнимые части совпадают).

5. **Преобразование**:
    * преобразование комплексного числа в полярную форму, где:
        * $r = \sqrt{a^2 + b^2}$ — модуль;
        * $\theta = \arctan\left(\frac{b}{a}\right)$ — аргумент (угол в радианах).
    * создание комплексного числа из полярной формы: $a = r \cos \theta$, $b = r \sin \theta$.

6. **Дополнительные операции**:
    * получение сопряжённого числа: для $a + bi$ сопряжённое — $a - bi$.
    * вычисление модуля комплексного числа: $|c| = \sqrt{a^2 + b^2}$.

7. **Вывод через строку**:
    * представление комплексного числа в виде строки. Формат:
        * если мнимая часть равна $0$, выводится только действительная часть;
        * если действительная часть равна $0$, выводится только мнимая часть с $i$;
        * иначе — в формате `"a + bi"` или `"a - bi"` (в зависимости от знака мнимой части).



8. **Бонусное задание**:
    * Возведение в произвольную комплексную степень.


## Примечания

* При всех арифметических операциях результат должен быть корректным комплексным числом.
* В полярной форме угол $\theta$ должен быть в диапазоне $[0, 2\pi)$ или $(-\pi, \pi]$.
* Модуль комплексного числа всегда неотрицателен.
* Не забывайте о нюансах сравнения чисел с плавающей точкой.
