# Задача «Счастливые билеты»

## Условие

Билет имеет номер из **шести цифр**.

Билет считается **счастливым**, если сумма первых трёх цифр равна сумме последних трёх цифр.

Например:
- `123321` — счастливый, так как `1 + 2 + 3 = 3 + 2 + 1`;
- `123456` — не счастливый.

## Задание

Напишите программу, которая подсчитывает:
1. количество шестизначных счастливых билетов;
2. процент счастливых билетов относительно общего числа шестизначных билетов.
