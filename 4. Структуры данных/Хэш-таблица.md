# Задача «Хэш‑таблица»

Реализовать хэш‑таблицу. Ключи — произвольные объекты.


## Требования к реализации

1. Хэш-таблица хранит пары `(ключ, значение)`, способ разрешения коллизий - на усмотрение преподавателя.
2. Начальный размер массива — настраиваемый параметр (по умолчанию — 100).
3. При заполнении таблицы сверх определенного порога, таблица должна автоматически расширяться — ёмкость удваивается, все элементы перераспределяются.
4. Поддерживать работу с произвольными хэшируемыми ключами (строки, числа, кортежи и т. д.).
5. Операции `put`, `get`, `delete` в среднем должны выполняться за O(1).
