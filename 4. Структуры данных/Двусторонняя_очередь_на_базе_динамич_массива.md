## Задача: «Двусторонняя очередь (дек) на базе динамического массива»

Реализовать абстрактный тип данных **двусторонняя очередь** (дек, deque) на базе **динамического** массива.

Дан интерфейс на языке C:

```c
typedef void *Pointer;

typedef struct tDeque {
    ....
} Deque;

void deque_create(Deque *d);
void deque_destroy(Deque *d);
size_t deque_size(Deque *d);
void deque_push_front(Deque *d, void *elem);
void deque_push_back(Deque *d, void *elem);
Pointer deque_pop_front(Deque *d);
Pointer deque_pop_back(Deque *d);
Pointer deque_peek_front(Deque *d);
Pointer deque_peek_back(Deque *d);
```

Требуется:

- самостоятельно определить содержимое `struct tDeque`;
- реализовать все функции интерфейса, не меняя их сигнатуры;
- дек хранит указатели `void *`, а не копии данных;
- `deque_create` создаёт пустой дек;
- `deque_push_front` помещает элемент в начало дека;
- `deque_push_back` помещает элемент в конец дека;
- `deque_pop_front` удаляет и возвращает первый элемент;
- `deque_pop_back` удаляет и возвращает последний элемент;
- `deque_peek_front` возвращает первый элемент без удаления;
- `deque_peek_back` возвращает последний элемент без удаления;
- `deque_size` возвращает текущее количество элементов;
- `deque_destroy` уничтожает дек, освобождая всю память, выделенную внутри дека; сами объекты, на которые указывают элементы, не освобождаются;
- при заполнении массива должна происходить **автоматическая** переаллокация;
- протестировать работу **каждой** из функций с помощью `assert`.
