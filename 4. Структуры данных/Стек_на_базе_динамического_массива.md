
## Задача: «Стек на базе динамического массива»

Реализовать абстрактный тип данных **стек** (LIFO) на базе **динамического** массива.

Дан интерфейс на языке C:

```c
typedef void *Pointer;

typedef struct tStack {
    ....
} Stack;

void stack_create(Stack *s);
void stack_destroy(Stack *s);
size_t stack_size(Stack *s);
void stack_push(Stack *s, void *elem);
Pointer stack_pop(Stack *s);
Pointer stack_peek(Stack *s);
```

Требуется:

- самостоятельно определить содержимое `struct tStack`;
- реализовать все функции интерфейса, не меняя их сигнатуры;
- стек хранит указатели `void *`, а не копии данных;
- `stack_create` создает пустой стек;
- `stack_push` помещает значение value на вершину стека;
- `stack_pop` удаляет и возвращает верхний элемент;
- `stack_peek` возвращает верхний элемент без удаления;
- `stack_size` возвращает текущее количество элементов;
- `stack_destroy` уничтожает стек, освобождая всю память, выделенную внутри стека; сами объекты, на которые указывают элементы, не освобождаются;
- при заполнении массива должна происходить **автоматическая** переаллокация;
- протестировать работу **каждой** из функций с помощью `assert`.
