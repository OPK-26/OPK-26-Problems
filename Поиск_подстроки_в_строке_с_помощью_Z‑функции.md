# Задача «Поиск подстроки в строке с помощью Z‑функции»

## Описание

Реализовать функцию `substring_search`, которая ищет все вхождения подстроки `pattern` в строке `text` с использованием **Z‑функции**. Функция должна возвращать список индексов, с которых начинаются найденные вхождения.


## Дополнительная информация

**Z‑функция** — это массив, где `Z[i]` — длина наибольшего общего префикса строки с её суффиксом, начинающимся в позиции `i`.
