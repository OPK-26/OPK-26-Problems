# Задача «Бинарный поиск в массиве»

## Условие

Дан массив `array`.

Элементы массива **не обязаны быть целыми числами** — это могут быть, например, вещественные числа, символы или строки.

Требуется найти индекс элемента, равного `elem`, используя алгоритм **бинарного поиска**.

Если элементов, равных `elem`, несколько, разрешается вывести индекс любого из них.

## Проверка работы программы
Оформите набор тестовых проверок с помощью `assert` из библиотеки `<assert.h>`, покрывающих различные случаи:
- элемент присутствует в массиве;
- элемента нет в массиве;
- массив состоит из одного элемента;
- массив пуст (`n = 0`);
- искомый элемент находится в начале, в середине и в конце массива;
- в массиве есть повторяющиеся элементы.
  Проверки необходимо провести для различных типов данных.
  Пример оформления проверок:

```c
assert(binary_search(arr1, 7, 7) == 3);
assert(binary_search(arr3, 1, 42) == 0);
```
