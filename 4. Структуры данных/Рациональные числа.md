# Задача «Рациональные числа»

## Описание

Необходимо реализовать модуль для работы с рациональными числами. Рациональное число представляется в виде дроби $\frac{a}{b}$, где $a$ — числитель, $b$ — знаменатель ($b \neq 0$).

## Требования

### Структура модуля

Создать два файла:
* `rational.py` — содержит класс `Rational` и все необходимые функции.
* `test_rational.py` — содержит тесты для функций из модуля `rational`.

### Класс `Rational`

Класс должен хранить числитель и знаменатель рационального числа.

### Функции

1. **Арифметические операции** (результат должен быть в каноническом виде — числитель и знаменатель сокращены на их наибольший общий делитель):
    * `add(a, b)` — сложение двух рациональных чисел.
    * `sub(a, b)` — вычитание двух рациональных чисел.
    * `mul(a, b)` — умножение двух рациональных чисел.
    * `div(a, b)` — деление двух рациональных чисел (убедиться, что делитель не равен нулю).

2. **Возведение в степень**:
    * `power(r, power)` — возведение рационального числа в целочисленную степень (может быть отрицательной).

3. **Конструирование**:
    * `create(numer, denom)` — создание рационального числа из числителя и знаменателя. Знаменатель не может быть равен нулю. При создании дробь должна быть приведена к каноническому виду.

4. **Сравнение**:
    * `compare(a, b)` — сравнение двух рациональных чисел:
        * возвращает $-1$, если $a < b$;
        * возвращает $0$, если $a = b$;
        * возвращает $1$, если $a > b$.

5. **Преобразование**:
    * `to_int(r)` — преобразование рационального числа в целое (отбрасывание дробной части).
    * `to_float(r)` — преобразование рационального числа в число с плавающей точкой.

6. **Вывод через строку**:
    * `to_str(r)` — представление рационального числа в виде строки. Формат:
        * если знаменатель равен $1$, выводится только числитель;
        * иначе — в формате `"числитель/знаменатель"`.

## Условия корректности

* При всех арифметических операциях результат должен быть приведён к **каноническому виду**: числитель и знаменатель должны быть взаимно простыми (сокращены на наибольший общий делитель), знаменатель должен быть положительным.
* При отрицательном рациональном числе знак хранится в числителе.
* Необходимо обрабатывать случаи отрицательных и нулевых значений, а также отрицательные степени в функции `power`.

## Пример использования

```python
import rational as r

a = r.create(3, 2)  # 3/2
b = r.create(1, 2)  # 1/2
c = r.add(a, b)     # 2 (результат в каноническом виде)
print(r.to_str(c))  # Вывод: "2"

d = r.power(a, -2)  # (3/2)^(-2) = 4/9
print(r.to_str(d))    # Вывод: "4/9"

e = r.compare(a, b)  # a > b, поэтому результат: 1
print(e)             # Вывод: 1
