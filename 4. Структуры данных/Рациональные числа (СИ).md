# Задача «Рациональные числа»

## Описание

Необходимо реализовать модуль для работы с рациональными числами. Рациональное число представляется в виде дроби $\frac{a}{b}$, где $a$ — числитель, $b$ — знаменатель ($b \neq 0$).

## Требования

### Структура модуля

Создать два файла:

*   `rational.h` — заголовочный файл, содержащий объявление структуры `Rational`, прототипы всех функций и необходимые константы.
*   `rational.c` — файл реализации, содержащий определение всех функций и вспомогательных методов.

Для тестирования создать файл:

*   `test_rational.c` — содержит функцию `main()` с набором тестов для проверки корректности работы всех операций.


### Представление данных

Рациональное число должно быть представлено следующей структурой:

```c
typedef struct {
    int num;   // числитель
    int den;   // знаменатель (всегда > 0)
} Rational;
```

### Функции

1. **Арифметические операции** (результат должен быть в каноническом виде — числитель и знаменатель сокращены на их наибольший общий делитель):
    * сложение двух рациональных чисел.
    * вычитание двух рациональных чисел.
    * умножение двух рациональных чисел.
    * деление двух рациональных чисел (убедиться, что делитель не равен нулю).

2. **Возведение в степень**:
    * возведение рационального числа в целочисленную степень (может быть отрицательной).

3. **Конструирование**:
    * создание рационального числа из числителя и знаменателя. Знаменатель не может быть равен нулю. При создании дробь должна быть приведена к каноническому виду.

4. **Сравнение**:
    * сравнение двух рациональных чисел:
        * возвращает $-1$, если $a < b$;
        * возвращает $0$, если $a = b$;
        * возвращает $1$, если $a > b$.

5. **Преобразование**:
    * преобразование рационального числа в целое (отбрасывание дробной части).
    * преобразование рационального числа в число с плавающей точкой.

6. **Вывод через строку**:
    * представление рационального числа в виде строки. Формат:
        * если знаменатель равен $1$, выводится только числитель;
        * иначе — в формате `"числитель/знаменатель"`.

## Условия корректности

* При всех арифметических операциях результат должен быть приведён к **каноническому виду**: числитель и знаменатель должны быть взаимно простыми (сокращены на наибольший общий делитель), знаменатель должен быть положительным.
* При отрицательном рациональном числе знак хранится в числителе.
* Необходимо обрабатывать случаи отрицательных и нулевых значений, а также отрицательные степени в функции `power`.

e = r.compare(a, b)  # a > b, поэтому результат: 1
print(e)             # Вывод: 1
