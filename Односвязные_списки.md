# Задача «Связанные списки»

## Описание

Необходимо реализовать модуль для работы с **односвязными списками** (singly linked list). Каждый узел списка содержит данные и ссылку на следующий узел. `None` трактуется как пустой список.

## Требования

### Структура модуля

Создать два файла:
* `slist.py` — содержит класс `SList` и все необходимые функции для работы со списком.
* `test_slist.py` — содержит тесты для функций из модуля `slist`, реализованные с использованием `assert`.

### Класс `SList`

Класс должен представлять узел односвязного списка и содержать:
* поле `data` — данные, хранящиеся в узле;
* поле `next` — ссылка на следующий узел списка (`None` для последнего узла).

### Функции модуля

1. **`length(lst)`**
    * Подсчитывает длину списка.
    * Если `lst` равен `None`, возвращает $0$.

2. **`prepend(lst, data)`**
    * Добавляет новый узел с данными `data` в начало списка.
    * Возвращает новое начало списка (новый узел).

3. **`get(lst, index)`**
    * Возвращает данные элемента по его порядковому номеру (`index`).
    * Индексация начинается с $0$.

4. **`remove(lst, index)`**
    * Удаляет элемент по его порядковому номеру.
    * Возвращает кортеж: `(данные удалённого элемента, новое начало списка)`.

5. **`append(lst, data)`**
    * Добавляет узел с данными `data` в конец списка.
    * Возвращает начало списка (может измениться, если список был пустым).

6. **`get_last(lst)`**
    * Возвращает данные последнего элемента списка.

7. **`find(lst, data)`**
    * Ищет первый элемент, равный `data`.
    * Возвращает индекс этого элемента (начиная с $0$).
    * Если элемент не найден, возвращает $-1$.

8. **`remove_first(lst, data)`**
    * Удаляет первый элемент списка со значением `data`.
    * Возвращает новое начало списка.
    * Если элемент не найден, список остаётся без изменений.

9. **`remove_all(lst, data)`**
    * Удаляет **все** элементы списка со значением `data`.
    * Возвращает новое начало списка.

10. **`copy(lst)`**
    * Создаёт полную копию списка.
    * Возвращает начало копии списка.

11. **`concat(lst1, lst2)`**
    * Присоединяет список `lst2` к концу списка `lst1`.
    * Возвращает начало объединённого списка.
    * Исходные списки не должны изменяться.

12. **`foreach(lst, func)`**
    * Проходит по всем элементам списка.
    * На каждом шаге вызывает функцию `func`, передавая ей данные текущего элемента.

13. **`find_custom(lst, predicate)`**
    * Ищет первый элемент, для которого функция‑предикат `predicate` возвращает `True`.
    * Возвращает кортеж `(значение элемента, индекс)`.
    * Если такой элемент не найден, возвращает `(None, -1)`.

14. **`from_list(list)`**
    * Создает связный список из обычного

15. **`to_list(list)`**
    * Создает обычный список из связного

---

## Условия корректности

* Все функции должны корректно обрабатывать `None` как пустой список. Например, `length(None)` возвращает $0$, а `prepend(None, x)` создаёт новый список с одним элементом.
* При попытке доступа к несуществующему элементу (например, `get` с некорректным индексом) вывести ошибку.
* Операции `remove`, `remove_first`, `remove_all` должны корректно обновлять связи между узлами.
* Функция `copy` должна создавать **глубокую копию** списка: изменения в копии не должны затрагивать оригинал.
* Функция `concat` не должна изменять исходные списки.

---

## Пример использования

```python
import slist

x = None
x = slist.prepend(x, "bb")
x = slist.prepend(x, "aa")

print(slist.get(x, 0))  # => "aa"
print(slist.get(x, 1))  # => "bb"

print(slist.length(x))    # => 2

y = slist.append(x, "cc")
print(slist.to_list(y))  # => ["aa", "bb", "cc"]

slist.foreach(y, print)  # Выведет: "aa", затем "bb", затем "cc"

index = slist.find(y, "bb")
print(index)  # => 1

z = slist.remove_first(y, "aa")
print(slist.to_list(z))  # => ["bb", "cc"]
