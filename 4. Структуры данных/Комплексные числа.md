# Задача «Комплексные числа»

## Описание

Необходимо реализовать модуль для работы с комплексными числами. Комплексное число представляется в виде $a + bi$, где $a$ — действительная часть, $b$ — мнимая часть, $i$ — мнимая единица ($i^2 = -1$).

## Требования

### Структура модулей
* `complex` — содержит класс/структуру `Complex` и все необходимые функции.
* `test_complex` — содержит тесты для функций из модуля `complex`.

### Python:
Класс должен хранить действительную и мнимую части комплексного числа.

### С:
Комплексное число задается структурой
```c
typedef struct Complex {
    double re;
    double im;
} Complex;
```

### Функции

1. **Арифметические операции**:
    * `add(a, b)` — сложение двух комплексных чисел.
    * `sub(a, b)` — вычитание двух комплексных чисел.
    * `mul(a, b)` — умножение двух комплексных чисел.
    * `div(a, b)` — деление двух комплексных чисел.

2. **Возведение в степень**:
    * `power(c, n)` — возведение комплексного числа в целую степень (может быть отрицательной).

3. **Конструирование**:
    * `create(real, imag)` — создание комплексного числа из действительной и мнимой частей.

4. **Сравнение**:
    * `compare(a, b)` — сравнение двух комплексных чисел на равенство (комплексные числа равны, если равны их действительные и мнимые части):
        * возвращает $-1$, если числа не равны;
        * возвращает $0$, если $a = b$ (действительные и мнимые части совпадают).

5. **Преобразование**:
    * `to_polar(c)` — преобразование комплексного числа в полярную форму, возвращает кортеж $(r, \theta)$, где:
        * $r$ — модуль;
        * $\theta$ — аргумент (угол в радианах).
    * `from_polar(r, theta)` — создание комплексного числа из полярной формы.

6. **Дополнительные операции**:
    * `conjugate(c)` — получение сопряжённого числа.
    * `absolute_value(c)` — вычисление модуля комплексного числа.

7. **Вывод через строку**:
    * `to_str(c)` — представление комплексного числа в виде строки. Формат:
        * если мнимая часть равна $0$, выводится только действительная часть;
        * если действительная часть равна $0$, выводится только мнимая часть с $i$;
        * иначе — в формате `"a + bi"` или `"a - bi"` (в зависимости от знака мнимой части).

## Примечания

* При всех арифметических операциях результат должен быть корректным комплексным числом.
* В полярной форме угол $\theta$ должен быть в диапазоне $[0, 2\pi)$ или $(-\pi, \pi]$.
* Модуль комплексного числа всегда неотрицателен.

## Пример использования

```python
import complex as c

a = c.create(3, 2)   # 3 + 2i
b = c.create(1, -1)  # 1 - i

# Арифметические операции
sum_ab = c.add(a, b)      # (3 + 2i) + (1 - i) = 4 + i
diff_ab = c.sub(a, b)     # (3 + 2i) - (1 - i) = 2 + 3i
prod_ab = c.mul(a, b)     # (3 + 2i)(1 - i) = 5 - i
quot_ab = c.div(a, b)     # (3 + 2i)/(1 - i) = 0.5 + 2.5i

print(c.to_str(sum_ab))    # Вывод: "4 + i"
print(c.to_str(quot_ab))   # Вывод: "0.5 + 2.5i"

# Возведение в степень
pow_a = c.power(a, 2)    # (3 + 2i)^2 = 5 + 12i
print(c.to_str(pow_a))      # Вывод: "5 + 12i"

# Сопряжённое число и модуль
conj_a = c.conjugate(a)   # 3 - 2i
mod_a = c.absolute_value(a)      # √(3² + 2²) ≈ 3.6056

print(c.to_str(conj_a))   # Вывод: "3 - 2i"
print(mod_a)              # Вывод: ~3.6056

# Полярная форма
polar_a = c.to_polar(a)  # (r, θ) ≈ (3.6056, 0.588)
print(polar_a)             # Вывод: (~3.6056, ~0.588)

# Создание из полярной формы
new_c = c.from_polar(2, 3.14159/4)  # ~√2 + √2i
print(c.to_str(new_c))    # Вывод: "~1.414 + 1.414i"

# Сравнение
comp_result = c.compare(a, b)  # a ≠ b, поэтому результат: -1
print(comp_result)        # Вывод: -1
